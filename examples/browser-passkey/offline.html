soroauth — sign an authorization entry offline

This page loads every asset from this directory and makes no request after load. It derives the Soroban authorization preimage and payload in the browser with the local WASM core, signs the payload with a passkey, writes the signature back onto the entry, and prints the signed entry. It does not submit anything and does not contact an RPC.

Offline protects the signing step on this page. It does not protect a compromised machine, an extension with access to the page, or the ledger state the entry commits to. See README.md in this directory.
